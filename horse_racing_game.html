Demonstrating Asyncio Concurrency in Python

Each horse = async def | asyncio.gather() = start all together | asyncio.sleep() = take a step

💡 How This Demonstrates Asyncio:

ASYNC Race: All horses run concurrently with asyncio.gather(). Time ≈ longest horse time.

SYNC Race: Horses run one at a time sequentially. Time = sum of all horse times.

Key Concept: asyncio.sleep() yields control to other tasks without blocking - that's why async is faster!
