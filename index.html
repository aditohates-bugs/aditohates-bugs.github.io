Async Programming

Slide 4

Coroutines don’t do much on their own until they’re tied to the event loop. By default, an async event loop runs in a single thread and on a single CPU core. In most asyncio applications, there will be only one event loop, typically in the main thread. Running multiple event loops in different threads is technically possible, but not commonly needed or recommended. Event loops are pluggable. You can write your own implementation and have it run tasks just like the event loops provided in asyncio.

loop = asyncio.get_running_loop()
